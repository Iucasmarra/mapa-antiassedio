# Roadmap

## Versão atual — Protótipo (v0.1)

Status: concluído

- [x] Telas navegáveis (mapa, registro, chat, perfil)
- [x] Mapa interativo com heatmap e filtros funcionais
- [x] Chatbot Astra IA com LLM real integrado
- [x] Botão SOS com notificação de contatos e autoridades
- [x] Fluxo de cadastro com configuração de contatos de emergência
- [x] Gerenciamento de contatos (adicionar, editar, excluir)
