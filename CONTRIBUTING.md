# Como contribuir

Obrigado pelo interesse em contribuir com o Mapa Antiassédio! Este é um projeto com propósito social e toda ajuda é bem-vinda.

---

## Antes de começar

1. Leia o [README](README.md) para entender o projeto
2. Veja o [ROADMAP](docs/ROADMAP.md) para entender as prioridades
3. Confira as [issues abertas](../../issues) para ver o que já está sendo discutido

---

## Como reportar um bug

Abra uma issue com o título `[BUG] descrição curta` e inclua:

- O que aconteceu
- O que era esperado
- Passos para reproduzir
- Navegador e sistema operacional

---

## Como sugerir uma funcionalidade

Abra uma issue com o título `[FEATURE] descrição curta` e descreva:

- O problema que a funcionalidade resolve
- Como você imagina que ela funcionaria
- Por que seria útil para os usuários do app

---

## Como contribuir com código

```bash
# 1. Faça um fork do repositório

# 2. Clone o seu fork
git clone https://github.com/SEU_USUARIO/mapa-antiassedio.git

# 3. Crie uma branch para sua contribuição
git checkout -b feature/nome-da-funcionalidade

# 4. Faça as alterações e commit
git commit -m "feat: descrição clara do que foi feito"

# 5. Envie para o seu fork
git push origin feature/nome-da-funcionalidade

# 6. Abra um Pull Request para a branch main deste repositório
```

---

## Padrão de commits

Use o padrão [Conventional Commits](https://www.conventionalcommits.org/):

| Prefixo | Uso |
|---|---|
| `feat:` | Nova funcionalidade |
| `fix:` | Correção de bug |
| `docs:` | Atualização de documentação |
| `style:` | Mudanças visuais sem alterar lógica |
| `refactor:` | Refatoração de código |
| `chore:` | Tarefas de manutenção |

---

## Código de conduta

Este projeto é sobre segurança e proteção de pessoas vulneráveis. Esperamos que todos os colaboradores mantenham um ambiente respeitoso, inclusivo e seguro nas discussões e contribuições.

Comportamentos inaceitáveis serão tratados com remoção imediata da discussão ou pull request.
